# Work Phase 3: A3 Project

This work phase focuses on **building and deploying your website**.

In this phase, you will:
- implement the website you proposed in Work Phase 2
- create and refine multiple webpages
- apply consistent structure, styling, and interaction
- deploy your website to the **UQCloud web server**

You are expected to **extend and refine** your work, not start again.

---

## Assessment context

This work phase is **Assessment Item A3**.

A3:
- builds directly on A2
- implements the website you proposed
- extends and refines your design rather than replacing it

Your A2 proposal should be clearly visible in your final implementation.

## Important note

In this course, **all assessment is completed as webpages**.

By the end of this phase, you will have a **working, deployed website**.
