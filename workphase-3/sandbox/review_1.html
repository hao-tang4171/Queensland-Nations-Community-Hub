Typography Review 1

What aligns with A2

  • Colours fully follow the A2 design system (terracotta #994B2D, ochre #B6965B, neutral background #F2F0E8).
  • The typography system (Quicksand + Noto Sans) and font size hierarchy remain unchanged.
  • The warm, non-commercial visual tone is consistent with the A2 design principles of respect, inclusivity, and cultural authenticity.

What does not align

  • Glassmorphism card style did not appear in A2 and is a newly introduced visual language.
  • The frosted glass background is more modern than the original solid-colour background in A2, representing a slight deviation from the original design. However, the colours still follow the colour palette established in A2.

Accessibility or readability concerns

After reducing the card opacity, we need to verify whether the contrast between text and background still meets the WCAG standard. The input fields use a semi-transparent background, and readability may decrease in areas with darker frosted glass backgrounds. However, the current contrast is still very high and does not affect readability.

Decision

The frosted glass background and glassmorphism cards will be retained, but it is necessary to confirm that the text contrast meets the required standards.

Issues found on the typography sandbox page

  • The heading sizes on mobile are too small, and the visual difference between H1 and H2 is not distinct enough.
  • The spacing between different headings and paragraphs is too narrow, which affects readability.

Cause and recommended CSS changes

The issue was caused by excessive compression of mobile font sizes in _typography.css — only a 0.2rem difference between H1, H2, and H3. Additionally, margin: 0 in _reset.css removed all default spacing, which was not restored in _typography.css. This resulted in an unclear heading hierarchy and tightly packed text.

The fix involves adjusting _typography.css to increase the font size ratio for mobile devices and adding global margins for headings and paragraphs. Both issues will be fixed at once, with changes applied across all pages.
